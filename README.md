# PHI-LAB v2.0 // Laboratorio Universale di Morfogenesi, Cristallografia, Biomeccanica & Analisi Aurea (φ)

Applicazione scientifica multidisciplinare pronta per **GitHub Pages** e ottimizzata per l'uso diretto con la **Claude GitHub App (Modalità A — senza API key)**.

## Novità della Versione 2.0 (Debuggata e Completa)
1. **Modulo A — Immagini con Algoritmo Anti-Bias di Sobel & Smart Auto-Crop**:
   - Calcolo del gradiente di Sobel su buffer offscreen pulito (zero inquinamento dai pixel della griglia).
   - Auto-Fit che testa tutte le orientazioni della spirale contro Griglia Aurea ($1.618$), Regola dei Terzi ($1.500$) e Rapporto $\sqrt{2}$ ($1.414$).
   - Modalità *Smart Auto-Crop* che trasla la finestra aurea per far cadere il baricentro visivo del soggetto esattamente sul nodo a $0.618$.
2. **Modulo B — Vera Geometria Molecolare/Cristallografica 3D (.XYZ) & Formule**:
   - Generazione 3D esatta dei 60 vertici aurei del **Fullerene $\text{C}_{60}$**, dell'**Icosaedro Platonico** e della catena di spin **$\text{CoNb}_2\text{O}_6$**.
   - Parser per coordinate molecolari `.xyz` personalizzate e formule chimiche con parentesi e pedici Unicode (`Ca(OH)2`, `CoNb₂O₆`).
3. **Integrazione Completa del Corpus di Ricerca**:
   - Identità di Cassini ($F_{n+1}F_{n-1} - F_n^2 = (-1)^n$), somme di Fibonacci e Medie Metalliche di Vera de Spinadel.
   - Regola di Hofmeister, Serie di Lucas ($99.5^\circ$) e pattern decussati ($90^\circ$).
   - Etnomatematica Africana (Palazzo Reale di Logone-Birni e trame *Kente*) e matrice di verifica delle tradizioni religiose (Euclide, Luca Pacioli 1509, Girih).
   - Protocollo musicologico a 4 livelli probatori con calcolo della probabilità di falso positivo $P = 1 - (1 - w)^n$.
4. **Laboratorio Cinetico 3D di Biomeccanica, Tango e Ritmo di Fibonacci**:
   - Modello 3D dell'asse corporeo, dissociazione toraco-pelvica a spirale (con allerta fisiologica oltre i $65^\circ$), ripartizione del peso avampiede/tacco e metronomo ritmico di Fibonacci.

## Come usarla con Claude GitHub App (Modalità A — Zero API Key)
1. Carica i file di questo archivio in un repository GitHub (es. `phi-lab`).
2. Installa l'app ufficiale **Claude** da `https://github.com/apps/claude` sul repository.
3. Apri `https://claude.ai/code` (o l'app desktop di Claude): seleziona il repository `phi-lab` e lavora direttamente con Claude (leggerà in automatico `CLAUDE.md`).
